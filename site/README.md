# サイト

このサイト自身のもの：名前、文言、ブランド、ページ、有効にするモジュール。手順は [業界の変え方](../docs/customize.md)。

| ファイル | 内容 |
|---|---|
| `site.ts` | サイト名、業界名、表示言語、タイムゾーン、トップページの文言、About ページ、シェア画像の文字 |
| `models.ts` | 名前付きのモデルと、各工程で既定に使うモデル（書いていない工程は `.env` で設定したモデル） |
| `brand/` | アイコン、ロゴ（`Logo.tsx`）、日報・週報・月報の題字 |
| `pages/` | 利用規約、プライバシーポリシー（ひな形。公開前に実際の状況に合わせて書き直す） |
| `public/` | サイトのルートにそのまま公開するファイル：`robots.txt`、`manifest.webmanifest`、`openapi-v1.json` |
| `changelog.json` | 更新履歴 |
| `modules/` | 有効にするモジュール（`modules/<名前>/`）。既定は空。[アーキテクチャ](../docs/architecture.md) の「モジュール」を参照 |
