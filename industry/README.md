# 業界パック

この業界（二輪市場）の知識はすべてここにある：分類、トピック、情報源、厳選の基準としきい値。別の業界に変えるときは、主にこのフォルダと [`site/`](../site/)（サイト名、文言、ブランド、ページ）を書き換える。手順は [業界の変え方](../docs/customize.md)。

| ファイル | 内容 |
|---|---|
| `taxonomy.ts` | カテゴリ、タグ、企業と団体、モデルが企業を取り違えないための語彙、この業界で最も注目される発表（`RELEASE`） |
| `topics.json` | トピック一覧（`/topics`）。サイトの起動時に読む |
| `sources.json` | 初回起動時に取り込む示範の情報源 |
| `prompts/` | 各工程のプロンプト：予備選別、採点、執筆、構造化、まとめ、出来事のまとめ、週報・月報、翻訳 |
| `selection.ts` | 入選のしきい値（二輪のサンプルで校正し直すまでは仮の値） |
| `gold.example.jsonl` | 厳選評価のサンプルの形式の例 |
| `relation-gold.example.jsonl` | 出来事の関係評価のサンプルの形式の例 |
