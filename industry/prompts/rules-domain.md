
【二輪分野の翻訳ルール — 本サイトの内容は 100% 二輪業界のもの。厳守する】

1. 曖昧な語の既定値：次の語は二輪の意味で訳す：
   - bike / motorbike / motorcycle = バイク、オートバイ（文脈が明らかに自転車でない限り「自転車」と訳さない）
   - scooter = スクーター、moped = モペッド（日本の制度に当てはまる文脈でだけ「原付」）
   - displacement = 排気量（数字の後は cc のまま）
   - naked = ネイキッド、adventure / ADV = アドベンチャー、cruiser = クルーザー、tourer = ツアラー、supersport = スーパースポーツ、café racer = カフェレーサー、scrambler = スクランブラー、off-road / dirt = オフロード
   - quickshifter = クイックシフター、traction control = トラクションコントロール、cornering ABS = コーナリング ABS、ride-by-wire = ライド・バイ・ワイヤ、cruise control = クルーズコントロール
   - registrations = 登録台数、shipments = 出荷台数、sales = 販売台数、production = 生産台数（互いに混同しない）
   - model year / MY = 年式（「2027 年モデル」）、launch = 発売・発表（どちらか原文で確かめる）、recall = リコール
   - pole position = ポールポジション、podium = 表彰台、championship = 選手権・タイトル、rider = ライダー

2. 次の固有名詞は原則として原文の表記を保ち、意訳しない：
   - メーカーは日本の二輪メディアで定着した表記に揃える：ホンダ、ヤマハ、スズキ、カワサキ、ハーレーダビッドソン、ドゥカティ、トライアンフ、ロイヤルエンフィールド、ピアッジオ、ベスパ、アプリリア、モト・グッツィ、ハスクバーナ、ビモータ、ベネリ。英字のまま書くもの：BMW Motorrad（または BMW）、KTM、GASGAS、CFMOTO、TVS、Bajaj、Hero MotoCorp、Zero Motorcycles、LiveWire、Gogoro
   - 車名と型式（例と一般ルール）：CB1000F / Ninja ZX-6R / MT-09 / GSX-8R / R 1300 GS / Panigale V4 / Himalayan 450 / XSR900 GP
     **ルール**：型式は一字も変えない（英字・数字・記号・スペースの位置を含む）。日本の公式カタカナ名がある車名（レブル、ホーネット、ハンターカブ、メグロなど）は、日本語の原文ではそのまま使う
   - 技術名・機能名の固有名：Eクラッチ（E-Clutch）、Y-AMT、DCT、e:HEV など。メーカーの表記どおりにし、一般名詞に言い換えない
   - レースと団体：MotoGP、Moto2、Moto3、WSBK（スーパーバイク世界選手権）、EWC、MXGP、ダカール・ラリー、鈴鹿 8 耐、JAMA（日本自動車工業会）、ACEM、SIAM

3. 数字と単位は **一字も変えない**：
   - 排気量 cc、出力 kW・PS・hp、トルク N·m、重量 kg、燃費 km/L は原文の単位を保ち、換算した値を書き足さない
   - 価格は原文の通貨のまま（$12,999 や €15,490 を円に換算しない）。税込・税抜の区別は原文どおり
   - 台数、前年比（%）、順位、シェアは原文の数字を一字も変えない。「約」「超」「前後」などの範囲の言い方も原文どおり
   - 年式と発売日は原文どおり。原文にない年を補わない

4. コード、URL、型番、品番は一字も変えない。
