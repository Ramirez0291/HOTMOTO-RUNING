
【タイトルの自己完結ルール — 読者が開かなくても「誰の何の話か」分かるように】

1. タイトルは中心の主体を必ず示す：車名、型式、メーカー名、団体名、イベント名。
2. 原題がすでに主体をはっきり示しているとき：外国語のタイトルは日本語に訳し、日本語のタイトルは意味を保つ。書き換えのための書き換えはしない。
3. 原題が型式だけ、コードネームだけ、情報量のない予告（「2027 Model」「Coming soon」「Day 1」「ついに登場」など）のときは、【情報源】と本文から主体をタイトルに補う。例：原題「Coming soon」＋情報源「カワサキ ニュース」、本文に Ninja 1100SX の新色 → 「カワサキ Ninja 1100SX に新色が登場予定」。
4. 主体を補うときは、【情報源】か本文に実際に出てくる名前だけを使う。本文にも情報源にも具体的な車名がなければ上位語（「新型スクーター」など）でまとめ、「業界の常識」で具体的な車名・型式・数字を決して作らない。
5. 原題が表す【記事の種類と中心の動作】は越えてはならない境界である：How / Why / Guide / Analysis / Review / Test / Comparison のような解説、分析、ハウツー、試乗、比較のタイトルは、日本語のタイトルでもその種類を保たなければならない。本文が既存の車種や新しい数字に触れているからといって「発表 / 発売 / 登場」に書き換えてはならない。原題が発表、発売、登場をはっきり宣言しているときだけ、日本語のタイトルも対応する動作を使える。種類を保つことは主体を消すことではなく、1〜4 に従って本文や情報源がはっきり示すメーカー名や車名を補う。
   例：原題 "Kawasaki Z900 review: still the best naked for the money?" → 「カワサキ Z900 試乗：価格に見合う最良のネイキッドか」。「カワサキが Z900 を発表」と書いてはならない。
   例：原題 "How to choose winter riding gloves" ＋情報源と本文が明らかにコミネの製品を紹介 → 「コミネの冬用グローブで見る選び方」。主体のない「冬用グローブの選び方」だけにはしない。
